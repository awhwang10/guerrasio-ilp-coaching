# Guerrasio Learner Remediation & Coaching Tool

A standalone, single-file web application designed to assist medical residency faculty mentors in coaching residents using the **Guerrasio Remediation Framework** (*Guerrasio et al., MedEdPORTAL 2017*).

## Overview
- **ILP Intake Checklist:** 24 common areas of struggle across 6 sections aligned with standard resident Individualized Learning Plan (ILP) self-assessments.
- **Dynamic Strategy Output:** Real-time diagnostic root causes, evidence-based Guerrasio remediation strategies, and editable SMART goal templates.
- **One-Click Copy Brief:** Formats selected coaching strategies and customized SMART goals into a clean text brief ready to paste into Semi-Annual Review forms.
- **Privacy First:** 100% client-side HTML/CSS/JavaScript with zero external dependencies and no data storage or transmission.

## Primary Reference
- Guerrasio J, Nogar C, Rustici M, Lay C, Corral J. Study skills and test taking strategies for coaching medical learners based on identified areas of struggle. *MedEdPORTAL*. 2017;13:10593. ## GitHub Pages Deployment
1. Upload `index.html` (and optionally this `README.md`) to a new GitHub repository.
2. In your repository on GitHub, go to **Settings** → **Pages**.
3. Under **Build and deployment** → **Branch**, select `main` (and `/ (root)`), then click **Save**.
4. GitHub will publish your live web app at `https://<your-username>.github.io/<repository-name>/`.
